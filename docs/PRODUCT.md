# meeshogi 初期版の製品仕様

この文書は企画相談で合意した初期版の範囲を記録する。実装済みの機能一覧ではない。実装方式の提案と未決事項は `ARCHITECTURE.md`、実装順序は `DEVELOPMENT.md` を参照する。

## 目的と提供範囲

ミーアキャットをマスコットにした、スマートフォン向け棋譜解析・戦績管理アプリ。iOS・Androidを同時に開発する。対局後に棋譜を取り込み、無料で解析・検討し、記録を蓄積できる体験を土台とする。

| 無料の初期版 | 将来の有料機能 |
| --- | --- |
| 端末内解析。利用回数による課金制限なし | LLMによる局面の解説・助言 |
| 棋譜保存、KIF書き出し、自由な分岐検討 | 一局の敗因や改善点の説明 |
| 基本戦績、代表的な戦型分類と集計 | 蓄積した棋譜からの傾向分析・AIコーチング |
| 1手詰め・3手詰めの検出と答えの確認 | 課金方式・価格・LLMモデルは別途決定 |

初期版はログイン不要。サーバー、同期、課金基盤は必須にしない。

## 棋譜の取り込みと保存

- 主対象は将棋ウォーズ・棋桜からクリップボードへコピーしたKIFテキスト。ユーザーが「棋譜を貼り付け」を押して取り込む。
- 棋譜一覧の「＋」から取り込みシートを開く。「貼り付け」を初期選択とし、「ファイル」ではOSのファイル選択からKIFを読み込む。どちらも同じ対局情報の確認・保存処理につなぐ。
- 取り込んだ対局情報を確認し、保存すると一局全体の解析を自動で開始する。自動解析は初期状態でオンとし、設定や取り込み時にオフにできる。オフで保存した棋譜も検討画面から解析を開始できるようにする。
- 対局日時、先後の対局者名、段級（存在する場合）、時間設定、指し手、各手の消費時間、終局理由と結果を保持する。
- 棋桜サンプルにはサービス名がない。KIFヘッダーだけでサービスを断定せず、登録名による候補やユーザーの選択で補う。
- サービスごとに自分の対局者名を登録する。複数名を登録でき、変更時も既存対局の帰属を確認・修正できるようにする。
- 自分の手番・勝敗を自動判定する。両者が登録名に一致するなど曖昧な場合は確認する。
- 自分を含まない棋譜も保存・解析できる。自分の戦績には含めない。
- 同一対局の再取り込みによる重複保存・二重集計を防ぐ。衝突し得る場合はユーザーが判断できるようにする。
- 本譜と解析結果は端末内に保存し、再起動後も開ける。個別棋譜はKIFとして保存・共有できる。
- 全件バックアップ・設定の一括復元は提案段階。初期版の必須条件は端末内保存と棋譜の書き出しであり、一括復元を追加の完了条件にしない。

元テキストも保持する方針とし、パース失敗時に一部だけを成功した対局として戦績へ登録しない。対象外の棋譜や不正な指し手では、分かる範囲で箇所・理由を表示する。

## 自動解析と検討

- 保存後に一局全体を端末内で解析し、完了した局面から評価値グラフへ反映する。
- 解析中も盤面操作、手送り、棋譜の閲覧ができる。停止・再開の手段を用意する。
- 候補手と読み筋を盤上で確認できる。気になる局面は追加で深く解析できる。
- グラフをタップして局面へ移動する。未解析区間を評価値ゼロとして描画しない。
- 評価値グラフと候補手の数値は先手視点に統一する。正は先手有利、負は後手有利とし、盤面を反転しても評価の符号・視点を変えない。
- 通常探索のmateは先手視点の符号を保った`+M5`／`-M5`で表示し、グラフでは符号側の端に置く。未解析は欠測として扱い、証明済みの1手／3手詰めバッジとは別に表示する。
- 保存済みの解析結果をすぐ開ける。解析の版や条件が変わっても、古い結果を新しい結果に見せかけない。
- 任意の局面から合法な指し手を入力し、その分岐の評価値・候補手を確認できる。
- 分岐内で手を戻して別の手を試せる。「本譜に戻る」で分岐を始めた本譜の局面へ戻れる。
- 分岐はその場の検討用とし、永続保存しない。本譜、全局解析グラフ、戦績を分岐の内容で上書きしない。
- 一局の解析予算、候補手数、深掘り予算、表示速度の目標はモバイル統合で測定して決める。研究リポジトリの探索条件をそのまま製品の固定値にしない。

## 短手数の詰みバッジ

- 初期版は1手詰めと3手詰め。本譜・分岐とも現在の局面の手番側を対象とする。
- 現在の手番側が連続王手で、相手のすべての合法な応手に対して詰ませられることを確認してから表示する。
- 1手詰めがあれば1手詰め。1手では詰まず3手以内で詰むことを確認した場合に3手詰めとする。
- バッジにはどちらが詰ませられるか分かる表示を付ける。現在の手番を入れ替えた仮想局面から詰みを表示しない。
- タップするまで答えを隠す。タップ後に代表手順を表示し、一手ずつ盤上で再生できる。閉じると元の局面に戻る。
- 詰み手順が複数ある場合も唯一解と断定しない。代表手順だけの確認を、全応手への詰み証明の代わりにしない。
- 未解析・中断・予算切れは「詰みなし」の証明ではない。3手までで未発見でも長手数の詰みを否定しない。
- 通常評価値の大きさ、候補手の一本の読み筋、LLMの推測を根拠に詰みバッジを出さない。

## 戦績と戦型

- 基本集計は通算・月別の勝敗と勝率、先後別、サービス別。
- 千日手・持将棋などの引き分けと、中断・結果不明を勝敗と区別する。勝率は勝ち／（勝ち＋負け）で表示し、引き分け件数を別記する。分母ゼロは未定義表示とする。
- 棋譜から相居飛車・対抗形・相振り飛車の対戦構図を自動判定する。
- 四間飛車・中飛車・三間飛車など代表的な戦法を自分／相手それぞれに分類する。最初に対応する厳密な戦法一覧と判定条件は実装時に文書化する。
- 序盤の駒配置と進行を参照し、単に終局時の飛車位置で判定しない。判別できない場合は未分類にする。
- 手動修正でき、自動再分類でその修正を黙って上書きしない。
- 自分が使った戦法別と、相手が使った戦法別に勝敗・勝率を確認できる。
- 代表戦法を主分類として集計し、転換や複数候補がある場合の選択規則を明示する。同じ対局を通算で重複集計しない。
- 囲いの自動判定と細かな戦法の網羅は初期版の必須範囲外。

## 画面構成

基本タブは「棋譜」「戦績」「設定」。起動時は棋譜一覧を開く。

| 画面 | 主要内容・操作 |
| --- | --- |
| 棋譜 | 最近の対局、対局相手、日時、勝敗、解析状況。検索、お気に入り、前回の続き。「＋」から取り込み |
| 棋譜取り込み | 貼り付け／KIFファイル、対局情報の確認、手番・結果・戦型の修正、保存して検討 |
| 解析・検討 | 上部に盤面、下に評価値グラフと候補手、下部に手送り操作。初期盤面は自分側が手前 |
| 分岐検討 | 同じ盤面上で検討。本譜との違いと「本譜に戻る」を見つけやすく表示 |
| 詰みの答え | バッジから開き、手順を盤上で再生。閉じると元の局面へ戻る |
| 戦績 | 基本集計と戦型別集計 |
| 戦型別戦績 | 選択した自分／相手の戦型について、勝率・先後別集計と該当棋譜を確認 |
| 設定 | 対局者名、解析、盤面と操作、表示テーマなど |
| 対局者名 | サービス別の複数名を登録し、先後の判定例を確認 |

主要9画面の[採用モックとデザイン基準](design/README.md)を実装の出発点とする。温かみのある白を基調に、盤面とグラフの視認性を中心に据え、小さなミーアキャットのマークで親しみを添える。基本3画面にタブを表示し、検討などの詳細画面は戻る操作、取り込み・詰め手順は閉じる操作で元の画面へ戻る。将来のLLM解説は解析画面へ追加できる配置を考えるが、初期版で使えない課金画面を主役にしない。

画像は見た目と情報配置の参照であり、盤面・手順・評価値・対局者名は表示サンプル。本書の将棋ルール・集計条件を優先し、サンプルの名前や解析値をアプリの初期値にしない。

## 初期版の対象外

- LLM解説・助言、課金の実装。
- ログイン、クラウド同期、端末間同期。
- 分岐の永続保存・分岐ツリー編集。
- 詰めろ・必至、5手以上の詰みバッジ。
- 囲いの自動判定、すべての戦法の網羅。
- 対局サービスの認証連携、棋譜スクレイピング。
- 対局サーバー、オンライン対戦、PC専用版。
