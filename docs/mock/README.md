# meeshogi HTMLモック

「一局を、次の一手に。」を軸にした、操作できるアプリのデザインプレビューです。meetermのアイボリー・茶の配色と手描きのミーアキャットを引き継ぎ、棋譜の一覧、将棋盤、戦績の数字を主役にしています。

## 開く

**[index.html](index.html) をブラウザで開いてください。** 画像・フォント・CSS・JavaScript・棋譜の表示データを内蔵しています。ビルドやインターネット接続なしで、このHTML一つから動きます。

ローカルサーバーを使う場合:

```sh
python3 -m http.server 8876 --bind 127.0.0.1 --directory docs/mock
```

ブラウザで `http://127.0.0.1:8876/` を開きます。SSH越しなら手元のPCで `ssh -L 8876:127.0.0.1:8876 server@server-Macmini` を実行し、手元の同じURLから確認できます。

- スマートフォン・幅899px以下: アプリ画面を表示。
- PC: アプリのプレビュー、画面切り替え、ライト／ダーク、iPhone／Androidのフレーム選択を表示。
- 初期画面の指定: `?view=analysis`、`?view=stats`、`?view=settings`。
- ダークの指定: `?theme=dark`。空の一覧: `?empty=1`。

フレームと画面幅の切り替えはブラウザでのデザイン確認用です。ネイティブのiOS・Androidアプリではありません。

## 試せる操作

| 画面 | 操作 |
| --- | --- |
| 棋譜 | 対局相手・戦型・日付の検索、勝敗／サービス／自分の戦型による絞り込み、対局を開く |
| 解析・検討 | 81マスの盤面、先後に応じた向き、盤面反転、持駒、成駒、手送り、自動再生、グラフからの局面選択 |
| 分岐検討 | 棋桜サンプルの32手目から「▲３六銀」を選び、３手の別手順を確認。本譜に戻ると32手目に復帰 |
| 取り込み | サービス選択→「サンプルを使う」→内容・自分の手番を確認→保存。空欄・対象外テキスト・重複を表示 |
| 対局情報 | サンプルのKIF書き出し、メモの保存、自分と相手それぞれの戦型を修正 |
| 戦績 | 月別／通算、勝敗と勝率、自分／相手の戦型別、先後別、サービス別。表示中のサンプルから計算 |
| 設定 | サービス別に複数の名前を登録、ライト／ダーク、空の一覧のプレビュー |

自分の対局者名は空で始まります。サンプル内の「あなた」は架空の対局者として固定した表示です。登録名からの本番の帰属判定は行いません。

このブラウザに、追加したサンプルのIDと手番、対局者名の設定、手動の戦型修正、メモ、テーマを保存します。`localStorage` が利用できない場合は保存の失敗を表示します。空の一覧を試しても、サンプル追加や設定は削除しません。

## デモとしての制約

- **実エンジン、通常探索、詰み証明は未接続です。評価値は固定のサンプルで、実際の棋力・局面評価を示しません。** 詰みバッジは出しません。
- 12局の一覧は架空の対局情報を使った表示例です。盤面の手順は、リポジトリの２局の棋譜サンプルを元にしています。対局者名は置き換えています。
- サンプルの戦型は配置から与えた表示用ラベルで、自動分類エンジンの結果ではありません。手動修正と、その集計への反映は動作します。
- 棋譜の取り込みは内蔵サンプルとの一致を確認する体験です。汎用KIFパーサー、実棋譜の保存、重複・勝敗判定の本実装ではありません。
- 分岐は用意した３手のサンプルに限定しています。任意の駒操作・合法手判定は未実装です。分岐に評価値や詰み判定を付けず、分岐を保存しません。
- 解析途中の対局は、未解析の評価値を「—」とし、グラフに未解析領域を表示します。停止・再開は固定結果の表示デモです。
- クリップボードの読み取りはブラウザ・実行元の制約を受けます。読み取れない場合も手動貼り付けとサンプル選択が使えます。
- モバイルの戻るジェスチャー、ソフトキーボード、シートのドラッグ、ハプティクス、実機の性能は、このHTMLで検証済みとは扱いません。

## ソースと再生成

- [src/index.template.html](src/index.template.html): PCレビュー表示、端末枠、モーダルの土台。
- [src/styles.css](src/styles.css): 色・文字・レイアウト・レスポンシブ表示。
- [src/app.js](src/app.js): 画面、状態、操作。外部ライブラリなし。
- [src/demo-data.json](src/demo-data.json): ２局の盤面・持駒・３手の分岐・匿名化したKIF。
- [assets/README.md](assets/README.md): 生成画像の出典・プロンプト、フォントのライセンス。
- [research.md](research.md): Appllamaとmeetermの参照記録。
- [verification.md](verification.md): 検証範囲と結果。

編集後、標準ライブラリだけでHTMLを再生成できます。

```sh
python3 docs/mock/build.py
```

元の棋譜サンプルを更新した場合だけ、`python3 docs/mock/src/prepare_demo.py` で盤面データを再生成します。この準備スクリプトは２つの既知の棋譜のためのものです。移動元の駒・手番、表記、持駒の残数、捕獲、昇格、全40枚の保存を確認しますが、汎用の合法手判定の代わりにはなりません。

フォントはモックの文字を含むWOFF2へサブセット化済みです。新しい日本語を追加する場合は、元フォントとFontToolsで文字を追加するか、該当文字のシステムフォントへのフォールバックを確認してください。

## ブラウザ確認の再実行

`verify.mjs` は、用意したローカルのPlaywrightとChromiumを使う確認スクリプトです。モックの実行時依存ではありません。ブラウザが用意された開発環境では次のように実行できます。

```sh
PLAYWRIGHT_MODULE=/path/to/node_modules/playwright \
CHROMIUM_EXECUTABLE=/path/to/chrome \
node docs/mock/verify.mjs
```

通常のPlaywrightインストールと対応ブラウザがNodeから解決できる場合、上の環境変数は不要です。`MEESHOGI_PREVIEW_URL` でサーバーのURLを変更できます。検証ごとに独立したブラウザを使用し、普段使いのブラウザの記録・設定は読みません。
