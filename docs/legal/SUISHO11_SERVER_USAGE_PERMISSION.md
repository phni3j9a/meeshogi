## 確認した利用形態

meeshogi では、以下の構成を想定して問い合わせを行った。

- 評価関数や実行ファイルを利用者へ配布しない
- 運営者が管理するサーバー上で実行する
- アプリへ返すのは評価値・候補手・読み筋などの解析結果のみ
- 無料枠と有料枠を設ける想定

> この形での利用は、配布時のライセンスで認められる範囲でしょうか。別途許諾が必要な場合は、確認先をご案内いただけますと幸いです。
