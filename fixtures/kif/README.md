## 実装時に確認すること

- 行頭空白、全角数字、全角コロン、`同　`の全角空白を扱う。
- `龍`と`竜`、成桂の`圭`、`歩成`・`銀成`、`金打`などを局面再生に反映する。
- 指し手の移動元と盤面を照合し、持駒・捕獲・成りを正しく追う。
- 投了の行は盤上の1手として加算しない。将棋ウォーズのサンプルは末尾の勝者文がなくても結果を取得する。
- 消費時間と累計を読み取り、元テキストを保存する。壁時計の対局時間を消費時間の合計と同一視しない。
- 棋桜のサービス名を汎用のKIFヘッダーだけで確定しない。
- 2局を登録して自分の通算が2勝0敗になる。再取り込みでも件数が増えない。
- 書き出し・再取り込み後に指し手、対局者、結果が維持される。

自分の名前はテストの設定値であり、アプリの固定初期値ではない。戦型や詰みの期待値はこの文書では断定しない。別途確認した専用ケースを追加する。

この段階ではサンプルの行番号・表記・終局期待値を整理しており、アプリのパーサーやエンジンを実行した証拠ではない。
