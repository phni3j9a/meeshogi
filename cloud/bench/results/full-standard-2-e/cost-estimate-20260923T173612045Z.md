# Staging benchmark cost estimate

- Price constants date: **2026-09-24**; currency: USD.
- Configured instance spec: **standard-2** (1 vCPU, 6 GiB memory, 12 GB disk; configuration values, not measured usage).
- Price constants: active vCPU-s $0.00002; provisioned GiB-s $0.0000025; provisioned disk GB-s $7e-8.
- Process CPU seconds below are **measured** from the engine process stats when available.
- Active-vCPU upper bounds and provisioned memory/disk seconds below are **conservative estimates**, not invoice values.
- Per-combo provisioned estimates add one 30-second sleep window, so summing combos intentionally overcounts a continuously warm matrix run.
- The estimates use request wall time; container image startup, preflight, idle gaps beyond the modeled window, egress, and account allowances are not metered here.

## Excluded items and caveats

- Workers / DO / Queue / D1: not metered — estimate excluded.
- Egress and logging: not metered — estimate excluded.
- Workers Paid monthly base charge and included allowances: not metered — estimate excluded.
- These values are a comparison aid. They are not an invoice, quote, or Cloudflare billing export.
